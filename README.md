# LyrIQ

LyrIQ analyzes lyrics of songs from the Billboard Hot 100 with a local LLM.

The CLI downloads chart history. Then it fetches lyrics. Then it writes analysis files.

## Commands

```
cargo run --release -- charts
cargo run --release -- lyrics
cargo run --release -- analyze --peak-max 10
```

`charts` writes unique songs to `data/songs.json`.
`lyrics` writes text files to `data/lyrics`.
`analyze` writes JSON to `data/analysis`.

If a lyric file already has a body, `lyrics` skips it.

## Lyrics coverage

The sources are LRCLIB, then NetEase Music.

As of 2026-08-24, 30,137 of 32,666 unique songs have lyrics (92.3%).
2,529 files have headers only.

The year of a song is the first week of that song on the Hot 100.

Most empty files are from 1958-1969 (1,523 of 2,529).
From 2000, the miss rate is less than 2%.

The peak miss year is 1961 (185 songs, 27%).
The peak miss rate is 1959 (28.3%).
